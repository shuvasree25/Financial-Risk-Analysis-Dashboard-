# Financial-Risk-Analysis-Dashboard
Financial Risk Analysis using PostgreSQL, SQL, Power Query, DAX and Power BI to analyze loan portfolio exposure, credit risk, defaults and financial impact.
# Executive Summary
The Financial Risk Analysis Dashboard is an end-to-end data analytics project focused on evaluating loan portfolio performance, credit risk, default patterns, delinquency, and financial exposure.
The project uses PostgreSQL and SQL for data storage and analysis, followed by Power Query, DAX, and Power BI for data transformation, KPI calculations, visualization, and interactive reporting.
The analysis covers 10,020 loan records from a USA-based loan portfolio and examines key indicators including loan exposure, outstanding balances, credit scores, debt-to-income ratios, missed payments, risk grades, collateral values, defaults, and delinquency.
The final Power BI dashboard contains three analytical pages covering portfolio overview, credit risk and borrower analysis, and loan default and financial impact.
# Business Objectives
The main objectives of this project are:
- Measure total loan portfolio exposure
- Analyze outstanding loan balances
- Identify default and delinquency patterns
- Evaluate borrower credit risk
- Analyze risk across different risk grades
- Identify high risk loan segments
- Evaluate collateral coverage
- Analyze default exposure by state and loan type
- Assess the financial impact of loan defaults
- Support data driven risk monitoring and decision-making
